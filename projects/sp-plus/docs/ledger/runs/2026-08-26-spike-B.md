## ISO build attempts

The brief permits four distinct ISO build attempts. Three were used, each with one hypothesis:

### Attempt 1 — rootless equivalent of the required command

**Hypothesis:** rootless Podman with the local rootless store and the same pinned image-builder would work if the installer and payload refs were available there.

```text
podman run --rm --privileged --network host \
  --security-opt label=type:unconfined_t \
  -v "$HOME/.local/share/containers/storage:/var/lib/containers/storage" \
  -v "$PWD/projects/sp-plus/artifacts/spikeB/out":/output \
  ghcr.io/osbuild/image-builder-cli@sha256:55ce154eaad86a4fcd43998588ccb6e15c801d25e392dab5c8073627f22ae37e \
  build --bootc-ref localhost/sp-plus-installer \
        --bootc-installer-payload-ref localhost/sp-plus-kde:spike \
        --bootc-default-fs ext4 \
        --output-dir /output --progress verbose \
        bootc-generic-iso
```

Verbatim result:

```text
chcon: failed to change context of '/var/cache/image-builder/store' to 'system_u:object_r:root_t:s0': Operation not permitted
error: entrypoint setup failed: error running chcon system_u:object_r:root_t:s0 /var/cache/image-builder/store: exit status 1
```

### Attempt 2 — disable SELinux labeling

**Hypothesis:** `--security-opt label=disable` would prevent the rootless cache relabel from running.

The invocation was the Attempt 1 command with `--security-opt label=disable` in place of `--security-opt label=type:unconfined_t`.

Verbatim result:

```text

error: entrypoint setup failed: error running chcon system_u:object_r:root_t:s0 /var/cache/image-builder/store: exit status 1
```

### Attempt 3 — put the cache on the output mount

**Hypothesis:** moving the cache to `/output/cache` would avoid the unlabelable default cache path.

The invocation was the Attempt 1 command with `--security-opt label=disable` and these additional builder flags:

```text

```

Verbatim result:

```text

error: entrypoint setup failed: error running chcon system_u:object_r:root_t:s0 /output/cache: exit status 1
```
