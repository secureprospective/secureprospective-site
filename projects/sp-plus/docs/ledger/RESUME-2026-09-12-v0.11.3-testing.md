## 6. DEFECTS FOUND — FIXED
1. **A marketer could write a flyer and then not export it.** `13b682a`.
   The data-boundary workspace exemption was `(?!Fin\/)` — it only excused the
   workspace when the path CONTINUED past it. `cd ~/Documents/Fin && soffice
   --convert-to pdf` and `--outdir .../Documents/Fin` end AT `Fin`, so both read
   as client data. Four phrasings refused. Now `(?!Fin(?:\/|[\s"';:,&|)\]]|$))`.
   Gate +7 cases incl. `Documents/Finances` and `Documents/Finn` which must STILL
   block. Mutation-checked: 3 of the new cases fail under the old rule.
2. **Every saved session was stamped `written_by: Fin using [object Object]`,
   and auto-save never rebuilt the index.** `c60ffbf`. Both mine from earlier today.
   **The real lesson: the recall gate's fixture passed `model` as a STRING where
   pi sends an OBJECT, so the gate was green all day while production was broken.**
   Fixture now sends the real shape; the handler accepts both.
