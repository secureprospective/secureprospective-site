# SP+ Paint Tide

Source file supplied by Christopher from his own wallpaper collection:
`~/Pictures/backgrounds/wp12665119-oil-painting-4k-wallpapers.jpg`, 3600x2032
JPEG, dated 2024-08-05.

The `wp########` filename is the naming convention of a wallpaper aggregator
site, so the ORIGINAL AUTHOR AND LICENCE ARE NOT ESTABLISHED. This is recorded
here rather than guessed at. Before SP+ ships publicly, either the upstream
licence must be confirmed or this image must be replaced. It is fine for
internal builds and test ISOs in the meantime.

UNLIKE THE OTHER SP+ WALLPAPERS, THIS SOURCE IS NOT 16:9. At 3600x2032 it is
1.7717:1 against 16:9's 1.7778:1, so a straight resize to a 16:9 screen would
stretch it. It is centre-cropped to 3600x2025, which removes 7 pixels of height
in total and touches nothing in the composition; the smaller sizes are then
downscaled from that crop.

No 3840x2160 size is shipped: the source is 3600 pixels wide, so a 4K entry
would be an upscale that adds file size and no detail. Plasma scales the
3600x2025 image for larger panels instead.
