# SP+ Blue Horizon

Source file supplied by Christopher from his own wallpaper collection:
`~/Pictures/backgrounds/wp11144398-minimalist-4k-blue-wallpapers.jpg`,
3840x2160 JPEG, dated 2024-08-05.

The `wp########` filename is the naming convention of a wallpaper aggregator
site, so the ORIGINAL AUTHOR AND LICENCE ARE NOT ESTABLISHED. This is recorded
here rather than guessed at. Before SP+ ships publicly, either the upstream
licence must be confirmed or this image must be replaced. It is fine for
internal builds and test ISOs in the meantime.

The source is 4K, so 3840x2160 is the original file unmodified and the smaller
sizes are downscales at 92% JPEG quality. NO 7680x4320 SIZE IS SHIPPED: the
source has no 8K detail to give, and upscaling would only make a larger file
that looks softer on an 8K panel than letting Plasma scale the 4K image itself.
The source is already exactly 16:9, so every size is a straight resize with no
change of composition.
