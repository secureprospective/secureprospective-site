# Backups: what is protected and what is not

**This verified SP+ image does not include an automatic backup program.** Do not mistake disk encryption, a system update rollback, a File Portal copy, or a USB drive for a confirmed backup of your work.

## What each protection actually does

| Protection or copy | Helps with | Does not prove |
|---|---|---|
| Disk encryption | Someone taking the powered-off computer | Recovery after deletion, a bad save, or drive failure |
| Going back after an update | Returning the operating system to an earlier version | Restoring your Documents or other personal files |
| File Portal | Keeping a file in the online file service | That the service's backup, retention, or recovery policy covers your need |
| USB or external drive | Making a separate copy | That the copy is encrypted, current, or the only copy you need |

The computer's protected system image is not a time machine for your work. Your documents live separately from that system image. If you delete or overwrite a document, going back after an update does not bring it back.

## What is missing today

No installed backup or file-sync client, and no scheduled backup service, was found in the current verified SP+ image. That is a product gap, not a task for you to solve by downloading a random backup program.

Until your practice has an approved backup arrangement, keep important work in an approved location and make an independent copy deliberately. Do not claim a client file is protected just because it exists in Documents, the File Portal, or on a USB drive.

## The one test that matters

A backup is useful only if you can open the copy when the original is unavailable. After making an approved independent copy:

1. **Open the copy from the other location.** Check that it is the right file and complete.
2. **Keep the original until that check succeeds.** Do not replace one uncertainty with another.
3. **Know who owns the backup process.** You, your practice, or a named service provider should be able to answer where copies are kept and how a file is recovered.

This is a working habit, not a compliance certification. Retention, client-data handling, and recovery responsibilities belong to your practice's policy.

## Let Fin help with the hard part

Fin can inspect this computer and help you understand what is present. Start with a non-destructive question:

- **"Fin, check whether this computer has a backup configured. Do not install or change anything."**
- **"Fin, help me understand what copies of this work file I should verify. Do not move or delete anything."**
- **"Fin, I need an approved backup plan for client work. Tell me the decisions I need from my practice before changing this computer."**

Do not give Fin passwords, recovery information, client records, or document contents. Ask it to check the computer and explain the options first.

## If a file is already missing

Stop making changes in the folder where it was last seen. Do not assume a restart, update rollback, or re-downloading an app restores the document. Ask Fin for a diagnosis promptly, then use [Getting more help](../advisor-help/getting-more-help.md) if the file matters to client work.
