# The file portal

The File Portal is the online place for client files: **cloud.secureprospective.com**. It opens in your browser and has its own sign-in page. It is not the same thing as the Documents folder on this computer, and it does not automatically turn every local file into an online one.

## What the File Portal is for

Use the portal when a client file needs to be kept in the SecureProspective file service instead of passed around in email attachments. It is a web service, so it needs an internet connection and your portal access. Welcome checks whether the service is ready before opening its details.

Your portal password is separate from your computer sign-in and from a back-office password. Do not reuse a password just because the names feel related. If you cannot sign in, do not keep guessing. Ask Fin to help you identify whether the problem is the portal, the browser, or this computer.

## Private and Shared are different places

The portal shows two important destinations:

- **Private** is for you alone.
- **Shared - your name** is for you and SecureProspective.

That difference is not cosmetic. It decides who can access a file. Read [Private and Shared: the rule that stops misfiling](private-and-shared.md) before you upload or move client work. If you are in doubt, leave the file where it is and ask Fin to explain the choice before you act.

## Opening the portal safely

Open **SP+ Welcome**, choose the **File Portal** service, and let it hand you to the browser. You can also go directly to **cloud.secureprospective.com** when you know you are using the correct address. The portal redirects to its sign-in page when you are not already signed in.

Before you put a file there, check these three things:

1. **The file is the final copy you intend to share or keep online.** Open it once before uploading.
2. **You chose Private or Shared on purpose.** Never use Shared just because it is more visible.
3. **You know whether a local copy still exists.** A downloaded or uploaded copy may need its own filing decision in Documents.

## Let Fin remove the uncertainty

Fin can help with the computer side of the task without needing your portal password or a client document. Try one of these prompts:

- **"Fin, I need to access the File Portal. What do I need before I sign in?"**
- **"Fin, I need to put a client file in the portal. Explain Private and Shared before I move anything."**
- **"Fin, the File Portal will not open. Check my computer and browser connection, then explain what you find."**

Do not paste a password, recovery information, client name, account number, or document contents into a request. If Fin asks for information that looks sensitive, stop and describe the problem without it.

## When the portal is not ready

A service can be temporarily unavailable even when the rest of your computer works. If Welcome says the File Portal is not ready, retry once after checking your normal internet connection. If it still fails, ask Fin for a diagnosis or use [Getting more help](../advisor-help/getting-more-help.md). Do not work around the problem by sending a client file to a personal email account.
