# Private and Shared: the rule that stops misfiling

This rule is simple and important: **Private is for you alone. Shared - your name is for you and SecureProspective.** Choose the folder by who needs access, not by which name feels more convenient.

## Ask one question before you file anything

**Does SecureProspective need this file to do a specific piece of work?**

- **No. Put it in Private.** It is your file alone.
- **Yes. Put it in Shared - your name.** That is the place for a file you intend to make available to SecureProspective.

If the answer is unclear, do not guess. Keep the file where it is for the moment and ask Fin to explain the choice. It is better to take a minute before filing than to untangle access after the fact.

## What each folder means

| Folder | Who can access it | Typical reason to use it |
|---|---|---|
| **Private** | You alone | A file SecureProspective does not need to see |
| **Shared - your name** | You and SecureProspective | A file you want SecureProspective to access for a named purpose |

Shared does not mean "put every client file here." It also does not mean an email attachment, a public link, or an instruction to send a file to someone outside SecureProspective. It is one deliberate access choice inside the File Portal.

## Use Fin before a difficult choice

Fin can turn a vague filing question into a clear next step. Tell it the work purpose, not the client details:

- **"Fin, SecureProspective needs to [purpose]. Should this file go in Private or Shared? Explain why before I move it."**
- **"Fin, I received a document that SecureProspective asked me to review. Help me decide where it belongs. Do not move it yet."**
- **"Fin, I am not sure who can see this folder. Explain the Private and Shared rule in plain language."**

Do not paste a client name, account number, password, recovery information, or document contents into the question. Fin needs the purpose of the file, not the private material inside it.

## If you think you chose the wrong folder

Stop before creating more copies or deleting anything. If a file may be in Shared when it should be Private, ask Fin or [Getting more help](../advisor-help/getting-more-help.md) promptly. Say which folder you chose and the file's purpose, not the client details. Do not assume moving a file back and forth fixes the access question.

## What this rule does not decide

Private and Shared decide the intended audience inside the File Portal. They do not answer whether a file is backed up, whether it is safe to send by email, or whether another copy exists on your computer. Those are separate decisions. Keep a clear local filing habit and use the portal deliberately.
