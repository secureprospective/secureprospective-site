# Coming from Windows

SP+ may look unfamiliar after Windows, but it is still a work computer: open an app, work in a window, save a file, and close it when you are done. You do not need to learn a new profession to get your work done.

## The Windows names you already know

A few names change. The job does not.

| In Windows | On SP+ | What it is for |
|---|---|---|
| Start menu | Applications menu | Finding and opening an app |
| File Explorer | **Dolphin**, the Files app | Seeing folders and opening files |
| Settings or Control Panel | **System Settings** | Changing a computer setting |
| Windows installer | **Fin** | Checking whether software is needed and adding it safely |

If you cannot see the equivalent of a Windows control, do not hunt through unfamiliar menus. Ask Fin what it is called here.

## The three things that feel different first

**Files have a different app name.** Open **Dolphin** when you want the same job as File Explorer. Your folders and documents are still yours. It does the same basic job.

**Settings are in one place.** Open **System Settings** for computer choices rather than looking for Control Panel. This is where a setting belongs when it affects the computer rather than one particular app.

**Software does not arrive as an `.exe` file.** A Windows download ending in `.exe` is not the safe installation route on SP+. Do not look for a workaround or a version from a random site. Tell Fin what you need and why. It can check whether the software is appropriate and do the difficult part.

## Use the Windows habit that still works: describe the job

You do not need to know the SP+ name for a feature before asking for it. Say what you are trying to accomplish. Fin can translate the Windows wording into the safe SP+ route.

Try one of these prompts:

- **"Fin, I used Windows for this. I need to [describe the task]. Show me the SP+ way."**
- **"Fin, this instruction is written for Windows. Is there a safe SP+ way to do it?"**
- **"Fin, this website wants me to download something. Do I need it, and can you handle the safe setup?"**

This is better than searching for a registry setting, a driver updater, or a repair download. Those are Windows answers to Windows problems. They are not automatically safe or useful on this computer.

## What not to carry over

Do not try to make SP+ behave like a copy of Windows. In particular:

- Do not download a cleaner, registry fixer, driver updater, or random installer to solve a problem.
- Do not follow a web page that tells you to type a technical command. Give the instruction to Fin and ask whether it applies.
- Do not turn off a protection just because a website or app asks. Ask Fin what the request means and what it changes.

This is not about taking control away from you. It is about putting the technical work with the tool that can inspect this specific computer before making a change.

## A simple first-week rule

Use the familiar apps and browser sites you need for work. When something feels different, pause before changing settings. Say the task out loud to Fin as if you were asking a colleague beside you. It can tell you where to go, carry out a repair, or explain why a Windows instruction does not fit.
