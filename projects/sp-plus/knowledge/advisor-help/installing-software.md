# Installing software safely

Use SP+ Welcome, **Discover**, or Fin when you need software. Do not treat a search result, browser pop-up, or Windows `.exe` file as the normal way to add an app. The safe route is visible and gives you a result you can check.

## Decide what job the app must do

Start with the outcome, not an app name. For example: "I need to join a client call," "I need a password manager," or "I need to scan from the office copier." Check with your practice before using any app for client work. An open software library is not a practice-approved list.

If the app will see client information, sign into an account, send a message, or connect to a service, ask what your practice approves before installing it. The right app for personal use is not automatically right for work.

## Use the named optional tools when they fit

In **SP+ Welcome**, open **Optional tools + store**. It offers **Bitwarden** and **Signal Desktop** as named optional additions. They install only when you choose their own add button. Welcome checks that the app is actually present before it says the installation is ready.

Bitwarden is for work logins when your practice uses it. Signal is an optional communication tool, not a substitute for your practice's decision about client communication. Do not add either one because a website or another person told you to without checking the work need first.

## Browse Discover, not the open web

The same Welcome screen can open **Discover**, the software library. It checks that the configured Flathub source is available before opening Discover. If that source is not available, Welcome reports that instead of pretending the store opened.

Discover lets you browse available apps, but browsing is not approval. Read what an app does, check the publisher, and ask your practice before using it for client work. If you find an app you want, write down its name and the job it would do before asking for help.

## Zoom is supplied as an SP+ base app

Zoom is supplied through SP+'s base-app setup, rather than something you need to find on a website. Check Applications first. If it has not appeared yet, ask Fin to check the safe next step instead of downloading another copy.

For a different call, scanner, signing, or business app, do not assume that an installer from a search result is the right version or the right approval path.

## Keep random installers out

Do not download a Windows `.exe`, a Mac `.dmg`, a browser extension, a driver disc, or a command copied from a web page to solve a work problem. Do not enter a password into an installer or pop-up you did not expect.

If a website claims you must install something immediately, pause. Open Fin and describe the outcome and the site name, without sharing a password or client information.

## Ask Fin for a checked route

Fin can check what is already installed and help with the safe installation path. Tell it what you need to accomplish and ask it to explain the change before it makes one. For example:

- **"Fin, I need a way to [task]. Check whether this computer already has it, then explain the approved next step before installing anything."**
- **"Fin, this site says I need [app]. Tell me whether it is safe and necessary for this computer before I add it."**
