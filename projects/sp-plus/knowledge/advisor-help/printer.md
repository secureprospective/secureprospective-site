# Printing

Printing from a normal app works much as it did on Windows. SP+ has its print service ready, but your office printer still needs to be identified and set up for this particular computer before it can receive a document.

## Print an everyday document

In Writer, Calc, a PDF reader, or most other apps, choose **File**, then **Print**, or use **Ctrl+P**. Check the printer name, the page range, and the number of copies before sending it. When a document contains client information, pause for that check. Sending a page to the wrong printer is an easy mistake to make and hard to undo.

If the printer you expect is already in the list, select it and print normally. If no printer is listed, do not keep retrying the same document. It needs to be set up first.

## Find the printer settings

Open the Applications menu and search for **Print Settings**. This is where the computer lists printers it already knows and where an office printer can be added.

Only add a printer you can identify. A shared office network can show several similar names. Use the name on the physical printer or its location, such as "reception" or "upstairs office", rather than guessing from a technical-looking address. If you cannot tell which one is yours, ask Fin before choosing one.

Do not download a driver, a browser extension, or a Windows `.exe` file to make a printer work. That is a common detour, not the safe route on this computer.

## Send one test page before important work

SP+ Welcome has a printer check in **Connect this computer to your office**. Choose **Print one test page** after the intended printer has been set up. Welcome checks for a usable printer first, then sends exactly one test-page job.

The result tells you whether the print system accepted the job. Pick up or look at the page before sending a proposal or a client record. A plain test page is a better test than a confidential document.

## If the printer is already set up but nothing arrives

Check the physical printer first: it needs power, paper, and no error message or jam showing on its own screen. Then check that the correct printer was selected in the print window.

If those checks fail, ask Fin and name the printer by location. Before any repair, ask which printer it sees. Its current scripted repair uses **Advisor Test Printer**, a test fixture, not office hardware. If that is all it names, it has not proved the office printer works.

Try a prompt such as:

- **"Fin, the printer by reception is not printing. Check the queue and printer state first, then tell me what you found."**
- **"Fin, I need to add the printer in the upstairs office. Check what this computer can see, tell me which one you plan to add, and ask before changing anything."**

Do not include a client name, document contents, password, or account information in the request. The printer location and the problem are enough to start.

## If you need a different kind of help

A printer may need a network connection, a setting in the app, or an approved change on the computer. Describe the outcome to Fin instead of trying random downloads: **"Fin, this document needs to print on [printer location]. Check the safe next step."**
