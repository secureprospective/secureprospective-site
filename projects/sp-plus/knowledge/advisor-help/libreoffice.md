# LibreOffice: your Word and Excel

SP+ includes LibreOffice for everyday documents and spreadsheets. **Writer** is the Word equivalent. **Calc** is the Excel equivalent. They are already installed, and the verified SP+ setup is configured to use Word and Excel formats for new work unless you deliberately choose another format.

## Start with the right app

Open **LibreOffice Writer** for letters, proposals, notes, and other documents. Open **LibreOffice Calc** for lists, calculations, budgets, and spreadsheets. You can find both in the Applications menu, or open a file from Dolphin and choose the appropriate app.

The names and controls are different from Microsoft Office, but the work is familiar: write, save, print, and share. Do not spend ten minutes looking for an exact Windows button. Tell Fin what you are trying to do and ask where that action lives in Writer or Calc.

## Save in a format others can open

Writer is configured to save new documents as Word `.docx` files, and Calc is configured to save new spreadsheets as Excel `.xlsx` files. The installed LibreOffice can also create those formats directly.

Before you send an important file:

1. **Save it with a clear name in Documents.** Keep the original working copy.
2. **Check the ending of the file name.** Use `.docx` for a Word document or `.xlsx` for an Excel spreadsheet when that is what the recipient expects.
3. **Open the saved copy once.** Check the first and last page, or the important spreadsheet tabs, before sharing it.

A familiar file ending is useful, but it is not a substitute for looking at the result.

## Treat complex files carefully

This manual has not verified every complicated Microsoft Office file. A document with unusual fonts, embedded objects, macros, complex formulas, or elaborate page layout deserves a careful review before it goes to a client or colleague.

Keep the original file. Work on a copy when possible. If something looks different after saving, stop before repeatedly saving over it. Ask Fin to explain the difference or ask support before changing the document again.

## Let Fin help without risking the original

Fin is useful for the difficult parts: finding a feature, drafting a new document, or helping you review what to check. It saves documents it creates in **Documents/Fin**, so your original work stays separate.

Try one of these prompts:

- **"Fin, I need to [describe the task] in Writer or Calc. Show me the safe SP+ way."**
- **"Fin, make a new draft in Documents/Fin for [purpose]. Do not change my existing file."**
- **"Fin, this Word or Excel file looks different after I saved it. Help me decide what to check before I share it."**

Do not paste client data, passwords, or the whole document into a request just to ask about formatting.

## When a document needs to be a PDF

Use the PDF page when you need a read-only copy, a form, or a signature workflow. A Word or Excel file is for editing; a PDF is usually for preserving the finished appearance.
