# Keyboard shortcuts

You do not need to memorize shortcuts to use SP+. The useful ones are the same familiar combinations from Windows and most work apps. Learn one or two that save you time; there is no prize for using the keyboard instead of the mouse.

## Copy, paste, and undo

These work in Writer, Calc, Brave, and most other apps:

| Keys | What they do |
|---|---|
| **Ctrl+C** | Copy the selected text, file, or item |
| **Ctrl+X** | Cut the selected item so you can move it |
| **Ctrl+V** | Paste what you copied or cut |
| **Ctrl+Z** | Undo the last change |
| **Ctrl+A** | Select everything in the current document, box, or page |

Copying is usually safer than cutting when you are unsure. Paste into the new place, check that it arrived, then remove the original only if you meant to move it.

## Save, find, and print

| Keys | What they do |
|---|---|
| **Ctrl+S** | Save your current work |
| **Ctrl+F** | Find a word or phrase in the current page or document |
| **Ctrl+P** | Open the print window |

Use **Ctrl+S** before closing a document, especially before attaching it to an email or uploading it. **Ctrl+F** is often faster than scrolling through a long PDF, web page, or spreadsheet. **Ctrl+P** opens the print choices; check the printer name and page range before you send anything.

## Move between open work

**Alt+Tab** switches between open windows. Hold **Alt** and tap **Tab** until the window you want is selected, then let go. This is useful when you are moving between a browser, a document, and an email without losing your place.

The key with the Windows logo is called the **Meta** key here. Press it by itself to open the Applications menu and start typing the name of an app. **Meta+D** shows the desktop, and **Meta+L** locks the screen immediately when you step away.

## Take a screenshot carefully

Press **Print Screen** to open SP+'s screenshot capture tool. Choose only the part of the screen you need. A screenshot can contain client names, account numbers, email previews, or browser tabs just as easily as a document can.

Before sharing one, look at it closely. Do not share private information in it or paste it into Fin, a public website, or an unapproved support chat. If you only need to show a technical error, capture the error itself rather than the whole desktop.

## If a shortcut surprises you

A shortcut may behave differently inside a particular website or app. That is normal. Use the menu instead, or ask Fin: **"Fin, I pressed [keys] in [app] and got [result]. Explain what happened without changing anything."**

You never need a shortcut to open a command line on SP+. If a help page or website tells you to type a command, stop and ask Fin for the safe route instead.
