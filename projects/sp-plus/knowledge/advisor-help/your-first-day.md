# Your first day: what Welcome set up

Welcome guides the first useful choices. Each part is separate, so do what helps today, skip the rest, and return later.

## Start with the things that make work easier

Welcome can help choose a desktop look, find the basic apps, read help inside the app, and open Fin. Preview a look, then confirm only if you want it. If a verified preview is unavailable, your current look remains.

## What Welcome can help with

| Need | What Welcome does |
|---|---|
| Find your way around | Shows the desktop map and the in-app help topics |
| Bring Fin into your work | Opens Fin in its own window so it can help with the hard parts |
| Check an office folder | Makes a temporary connection check, then removes that connection when the check ends |
| Test a printer | Checks the print service and sends one test page only when a printer is ready |
| Start email | Opens your provider's own web sign-in page |
| Add an optional tool | Offers Bitwarden and Signal as separate choices |

Welcome does not need to be the place where you solve every problem. Use it to start a task, then bring Fin in when the next step is unclear.

## Be clear about office connections

The office-folder step is a **check**, not a permanent drive left open on your computer. Have the office server name, shared-folder name, and office username ready. If you choose to save the folder credentials, Welcome uses the desktop wallet. If you do not know those details, do not guess or borrow someone else's login. Ask Fin: **"Fin, I need to check my office folder. What information should I have before I start?"**

The printer step sends exactly one test page after checking that the print service and a printer are ready. The email step opens the provider's own sign-in page. **Welcome does not ask for or store your email password.**

## Let Fin take the hard parts

Open Fin from Welcome when a task is technical, unclear, or simply not worth fighting alone. Describe the job, not the jargon. For example:

- **"Fin, I am setting up this work computer. What should I do first?"**
- **"Fin, I need to connect to the office folder. Tell me what you need from me, then handle the technical part."**
- **"Fin, I need Bitwarden for work logins. Help me set it up without creating duplicate password stores."**

If Fin asks you to connect a provider, follow its on-screen guidance. It does not need a key or password from an email. Do not give Fin client records, passwords, recovery information, or a sensitive document as a first test.

## What can wait

Bitwarden and Signal are optional tools. Adding them is your choice, not a requirement to finish Welcome. The same applies to the office-folder check, printer test, and email sign-in. A skipped step means "not today," not "broken."

When you do add something, keep the result simple: confirm that it opens or the one test page prints. If it does not, ask Fin what it found instead of repeating the setup several times.

## Return when you need it

You can reopen **SP+ Welcome** from **Applications** at any time. Return for help, to review a skipped office task, to open Fin, or to make another optional choice. Closing Welcome does not close Fin.
