# Changing how it looks

SP+ starts with a dark Windows-style desktop. You can change its appearance, but change one thing at a time. A theme can alter colors, wallpaper, icons, pointer, fonts, windows, and panel.

## Choose the SP+ light or dark look

Open **System Settings**, then **Global Theme**. The checked image includes:

- **Modern Dark**, the current checked default.
- **Modern Light**, the matching light version.

Choose one and follow the confirmation shown. Check a browser and document before deciding. Do not combine theme, display-scale, font, icon, and panel changes. If it feels wrong, return to Global Theme and choose **Modern Dark**.

## What a global theme can change

A global theme changes several appearance choices together, not just color. The supplied SP+ themes have different colors and window decoration, plus wallpaper, icons, pointer, fonts, and panel-related settings.

Do not use a theme change to solve a printing, sound, login, file, or network problem. If an app looks wrong only after a theme change, return to the previous theme before unrelated repairs.

## Change one smaller thing when that is all you need

System Settings also has **Fonts**, **Colors**, **Application Style**, **Icons**, and **Pointers**. Use one only for a specific comfort problem, such as hard-to-read text or a difficult pointer.

Make one adjustment, check it in a browser and document, and keep it only if it helps. The controls and their visible result were not tested on advisor hardware. Ask Fin before changing several things.

## Keep display size separate from the theme

Text size, screen scaling, and a second monitor affect readability without changing the global theme. If another screen looks wrong, use the related Second monitor problems page. Do not change every appearance setting at once.

A wallpaper or color change does not make client data private. Lock the screen and close unrelated material before a screen share.

## Avoid downloaded themes and extensions

Do not install a theme, wallpaper program, browser extension, or Windows `.exe` file just because it promises a familiar desktop. The image already contains appearance components. A download can change more than the look or ask for unrelated permissions.

If the supplied choices do not solve the comfort problem, ask Fin without naming client files or showing a sensitive screenshot. For example: **"Fin, the text is difficult to read. Show me one safe setting to check."**

## What was checked

The checked virtual machine uses **Modern Dark** with its dark color scheme and supplied cursor. Both SP+ themes and the listed pages are installed. This manual did not interactively apply a theme, test its panel layout, or check physical displays.
