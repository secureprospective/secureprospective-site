# Scanning documents

SP+ includes the underlying support needed to find compatible scanners, but the verified starting image does not include a scanning app or a Scan icon. That is deliberate and honest: scanner models and office workflows differ, so the right setup needs to match the device you actually use.

## Start with the outcome, not a download

Before setting anything up, decide what the finished file needs to be. For most paper records, that means a readable PDF saved in the right place. Decide whether it belongs in **Private** or **Shared** before you scan it. Do not use a client document as a test page.

If the device is a printer with a scanner on top, the scanning side is a separate job from printing. A printer that can make copies or receive a print job is not proof that this computer is ready to receive scans from it.

## Ask Fin to check the device first

Tell Fin the make and model if you know it, whether it is connected by USB or on the office network, and where it is located. Fin can check whether the computer can see the device and recommend the safe next step. Ask for an explanation before any app or setting is added.

Use a prompt such as:

- **"Fin, I need to scan from the copier by reception. Check whether this computer can see it and explain the safe next step before changing anything."**
- **"Fin, this USB scanner is a [make and model]. Check compatibility and ask me before installing or changing anything."**

You do not need to send Fin the document, a client name, a password, or account information to get help with scanner setup.

## Do not assume the printer screen is the safe route

Many multifunction devices offer choices such as scan to email, cloud storage, USB, or a network folder. Those choices can send a copy somewhere outside the computer. Do not choose an unfamiliar destination for a client document just because it is convenient. Ask Fin or your practice first which destination is approved.

If a device asks for an office email password, cloud password, or folder password, stop before entering it. Use the practice's approved setup route, not a password copied into an unfamiliar printer screen.

## Once scanning is set up

Use a plain, non-sensitive page for the first test. Then open the saved result and check that every page is present, readable, and facing the right way before you file or send it.

Put the finished file in the place you chose before scanning. **Private** is for you alone. **Shared** is for files SecureProspective needs to see. If the scan is going to a client or another service, confirm the recipient and file before sending it.

## If the computer cannot see the scanner

Do not download a driver from a search result or try random browser add-ons. Scanner compatibility is specific to the model and connection. Tell Fin the model, whether the scanner is plugged in or on the same office network, and what you were trying to do. Fin can narrow down whether the next step is connection, approved software, or a practice setup decision.
