# Finding Your Way Around

SP+ looks and works like Windows, on purpose. Skim this once and you will know where everything is.

## The desktop

You will recognize most of it immediately:

- **The taskbar** runs along the bottom of the screen, just like Windows. Open programs appear on it. Click to switch, right-click for options.
- **The start menu** is the icon at the bottom-left corner. Click it to see all your programs, search for anything by name, and shut down or restart.
- **The system tray** sits in the bottom-right corner: Wi-Fi, volume, battery, clock. Click any icon to adjust it.
- **Files** are managed in an app called **Dolphin**. It works like File Explorer: sidebar with common folders, double-click to open, drag to move. Find it in the start menu.
- **Settings** live in an app called **System Settings** (start menu, then search "settings").

**Making text bigger:** open System Settings, search for "display", and use the scaling control. Slide up until text is comfortable, then apply.

## The things you will do most days

| Task | How |
|---|---|
| Open your work apps | Use the browser. Bookmarks are already organized. |
| Save a file | Any app's save dialog; your Home folder is the safe default |
| Print | Ctrl+P, then pick your printer. See [Printing help](../troubleshooting/printer-not-printing.md) |
| Lock the screen | Close the lid, or wait a few minutes, or use the power/menu area to lock now |
| Shut down or restart | Same place you found the lock option |

## Keyboard shortcuts worth learning

These are worth learning:

- **Ctrl+C, Ctrl+V, Ctrl+X**: copy, paste, cut. Exactly as you expect.
- **Alt+Tab**: jump between open windows.
- **Ctrl+Alt+T** is deliberately not needed here: this computer is designed so you never have to touch a command line.
- **The Super key** (the one with the Windows/Command logo): opens search or Activities, depending on edition. Treat it as "find anything" button.

## When something looks wrong

Screens can end up stretched, duplicated, or dim after plugging in projectors or monitors. See [Second monitor problems](../troubleshooting/second-monitor.md). For anything else, ask the Assistant: [Asking the Assistant](asking-the-assistant.md).
