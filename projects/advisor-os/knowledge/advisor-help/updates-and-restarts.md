# Updates and Restarts

Advisor OS updates itself. You never search for updates, download anything, or run an updater. This page explains what actually happens, so updates never feel mysterious.

## The normal rhythm

1. **An update downloads quietly** while you work. Nothing changes on your screen; nothing slows down noticeably.
2. **A small notice appears** telling you a restart will complete the update. There is no countdown forcing you off the computer.
3. **You restart when convenient.** Coffee break, lunch, end of day. During the restart, the update finishes in moments.
4. **Done.** You are on the new version, with all your files, bookmarks, passwords, and settings exactly where you left them.

Restarting at the end of the day once or twice a week is plenty. If you restart rarely, the notice gets slightly more insistent, but it will never force your hand mid-task.

## Why updates here cannot wreck the computer

On most computers, an update rewrites parts of the system while it runs. If power dies halfway through, or an update turns out to be faulty, the system can be left damaged.

This computer works differently. Each update is prepared as a **complete, ready-to-run version of the system**, built alongside your current one. The running system is never touched while you use it. At restart, the computer simply switches to the new version.

That design gives you two guarantees:

- **A failed update fails harmlessly.** If downloading or preparing an update goes wrong, your current system keeps working normally and the update simply tries again later.
- **There is always a way back.** Your previous version stays on the disk. In the rare case where a new version misbehaves, the previous one remains available at startup as an automatic undo. Your files are untouched either way; the undo applies to the system, never to your documents.

## "Do I need to install anything myself?"

Almost never. Everything you need day to day arrives through these automatic updates or is already installed.

If you want an extra program, look in the software library on this computer first. Programs there are packaged safely and install cleanly. Avoid downloading installers from random websites; on this computer they generally will not install anyway, because the core system refuses outside modification. That refusal is not a limitation to work around. It is the same mechanism that makes this computer hard to infect.
