# UI component resources — verified 2026-09-02

> **Procurement rule (Christopher, 2026-09-02): no paid services.** Only genuinely free,
> unmetered tools are kept below. A metered free tier is treated as a paid product and is
> excluded. Where a resource has a free core and a paid Pro tier, only the free core is in
> scope and the Pro tier is off-limits.

Source list supplied by Christopher (originally generated by Gemini). Every entry below was
fetched and confirmed to exist and to be what it was described as. Corrections to the original
description are marked **[correction]**.

## Stack reality check

This site is **Astro 4 + GSAP 3, hand-written CSS with design tokens** (`src/styles/tokens.css`,
`site.css`). There is **no Tailwind and no React** in `package.json`. That governs how each
resource below can actually be used.

## 1. Copy-and-own (React + Tailwind)

- **shadcn/ui** — https://ui.shadcn.com/ — Confirmed. Copy-paste source components, React +
  Tailwind, built on Radix, by shadcn at Vercel. Not directly usable here without React+Tailwind;
  useful as a **spec/reference** for structure and accessibility behaviour.
- ~~**21st.dev** — https://21st.dev/~~ — **EXCLUDED, do not use.** Confirmed to exist, but it
  is a metered freemium marketplace: **two component copies per day**, then paid membership,
  plus a paid "21st AI" add-on. Gemini's "open-source" description was wrong. A daily quota is a
  paywall, so this fails the no-paid-services rule and is out of the inventory.
- **Aceternity UI** — https://ui.aceternity.com/ — Confirmed. 200+ landing-page components,
  React + Tailwind + Framer Motion, shadcn-compatible. **[correction]** Gemini implied it belongs
  in the free copy-and-own tier; it is **freemium**. **Free components only — the paid All-Access
  Pass is off-limits.**
- **Magic UI** — https://magicui.design/ — Confirmed. 150+ free, open-source animated components;
  React + TypeScript + Tailwind + Motion; ~22k GitHub stars. Pro tier adds 50+ blocks/templates.
  Description accurate.

## 2. Pre-built utility and component libraries

- **daisyUI** — https://daisyui.com/ — Confirmed. Tailwind plugin, semantic class names
  (`btn`, `card`, `navbar`), **pure CSS with no JavaScript**, framework-agnostic (Astro listed).
  v5.7.27, ~42k stars, 68 components. Of everything on this list, the **most compatible with an
  Astro site** if Tailwind is ever added.
- **Preline UI** — https://preline.co/ — Confirmed. 1,600+ components/blocks, HTML/JS/TS on
  Tailwind, Astro supported, ships an MCP server. **[correction]** Gemini said "100% free open
  source". It is **not** — the free tier is 640+ components and 220+ blocks, with a **Preline Pro**
  paid tier for premium templates.
- **HyperUI** — https://www.hyperui.dev/ — Confirmed (site 403s automated fetches; verified via
  the repo at https://github.com/markmead/hyperui). Free **MIT-licensed** Tailwind v4 components,
  no install, marketing / e-commerce / application UI, dark mode and Alpine JS variants.
  Description accurate — genuinely free, unlike several above.
- **Flowbite** — https://flowbite.com/ — Confirmed. **MIT-licensed** Tailwind components with
  vanilla JS (ESM/CJS, TS types), 56+ component types, 430+ free icons, Figma files, Astro
  supported. Description accurate. **MIT core only — paid Flowbite Pro / Blocks is off-limits.**

## 3. Unstyled primitives

- **Radix UI** — https://www.radix-ui.com/ — Confirmed. Open-source React library; Primitives are
  the unstyled accessible layer under shadcn/ui, alongside Themes, Icons and Colors. React-only,
  so reference value here rather than direct use.
- **Headless UI** — https://headlessui.com/ — Confirmed. By **Tailwind Labs** (the Tailwind team),
  unstyled fully accessible components for **React and Vue**. React/Vue-only — same caveat.

## What this means for this site

Eleven resources remain in the inventory after 21st.dev was excluded on cost. Nine of the twelve
originally listed assume Tailwind, and six assume React. The genuinely
directly-applicable free ones for an Astro + vanilla-CSS site are **HyperUI**, **Flowbite** and
**daisyUI** (the last two MIT / free), and **Magic UI** as an animation-technique reference whose
effects can be reimplemented in GSAP against the existing token system. The React-based
libraries are best used as **design and accessibility references**, not as code to import.
