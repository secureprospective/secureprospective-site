## Checked and clean
- Passwords use scrypt with a per-user salt and constant-time compare. Sessions use 256-bit random tokens stored as hashes, with HttpOnly, Secure and SameSite=Lax cookies.
- All SQL is parameterized. Every admin route calls `requireAdminSession`. No admin can demote or remove their own account.
- The ISO, list, me and admin routes return 401/403 without a session (verified live). R2 is private: the old token returns 401 and the new one is scoped.
- Git history holds no secrets. The `0x4AAA…` strings are 24-character Turnstile site keys, which are public.
- Lead email HTML is escaped. The lead form uses Turnstile, fails closed, and has length caps.
- SPF, DKIM and DMARC `p=reject` are set on the root domain. HSTS, `frame-ancestors 'none'`, nosniff and Referrer-Policy are present.
- No `.git`, `.env`, source, or `dist` exposure on production.
